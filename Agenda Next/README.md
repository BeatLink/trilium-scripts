# Agenda Next

## Overview

Agenda Next is a project to consolidate existing scripts in this repository into powerful widgets, providing improved UI/UX, simplified code, and better performance. Agenda Next currently comprises 3 widgets:

## Task Widget

This is a powerful widget for converting notes into tasks. It provides options for setting start and due date, powerful recurrence, priority with color coding, as well as the option to reschedule or mark the task complete.

## Agenda Now

* Floats on top of all windows for easy access
* Inbox page can be used for quickly writing down notes and tasks
* Built In Countdown Timer
  * If current note has a duration label, countdown timer will be automatically set
* Currently due notes from Agenda Overview are automatically added to Inbox Note
* Can be automatically launched on startup
* Sends notifications for currently due tasks
* Tasks can be marked done directly from widget
