# Template Picker

A right-pane widget that lets you assign or change the template of the currently active note.

## How it works

The widget appears in the right pane and shows a dropdown of all notes labelled `#template`. Selecting a template sets a `~template` relation on the current note. Selecting "None" removes the relation.

To hide a template note from the picker, add `#noTemplatePicker` to it.
