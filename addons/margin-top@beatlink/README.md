# Margin Top

Adds extra top padding to notes in the tree view that have the `#cssClass=margin-top` label.

## Overview

A minimal CSS snippet that visually separates groups of notes in the left-panel tree by adding `2rem` of top margin above any note styled with the `margin-top` CSS class. Useful for creating visual section breaks between headings or top-level groups in a dense note tree.

## Usage

Add the label `#cssClass=margin-top` to any note you want extra spacing above in the tree.
