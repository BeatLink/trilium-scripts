# ToggleNote

ToggleNote adds configurable buttons that let you quickly add or remove the current note as a child of one or more parent notes.

## Features

- **Multiple launchers** — configure any number of parent notes as targets
- **Exclusive mode** — when adding to a parent, automatically remove from all other configured parents first
- **Flexible placement** — display buttons in the right pane or as icons in the left pane launchbar

## Settings

Open the ToggleNote settings note to configure the addon:

- **Exclusive Mode** — toggle on to enforce single-parent behaviour
- **Launcher Placement** — choose between Right Pane and Left Pane Launcher; reload the UI after switching
- **Launchers** — add, remove, and reorder parent note targets using the note autocomplete picker
