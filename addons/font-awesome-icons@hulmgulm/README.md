# Font Awesome Icons

Two [Trilium icon packs](https://docs.triliumnotes.org/user-guide/concepts/themes/icon-packs) built
from Font Awesome 7.3.1 Free, so its icons can be picked as note icons alongside the built-in
Boxicons.

| Note | Prefix | Contents |
|------|--------|----------|
| Font Awesome Icons | `fa-solid` | The free solid icon set. |
| Font Awesome Brand Icons | `fa-brands` | The free brand/logo icon set. |

## Usage

Install and enable the addon, then [refresh the client](https://docs.triliumnotes.org/user-guide/troubleshooting/refreshing-the-application).
Both packs then show up in the icon picker's source filter, and their icons can be set by hand as
`#iconClass="fa-solid fa-rocket"`.

Disabling the addon renames the `#iconPack` labels, which takes both packs out of the picker without
uninstalling anything.
